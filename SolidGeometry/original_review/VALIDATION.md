# 原题审核交付核验

核验日期：2026-10-11。环境：Python 3.13.9、Matplotlib 3.11.2、NumPy 2.5.3、Pillow 12.3.0。

## 候选和现有正式库

- 168 个候选，原始来源记录和来源图片逐一与上游固定快照一致；未带回已排除的 27 题。
- 168 个候选的答案类别、选择题映射、真实来源、独立答案/证明和来源答案比较均完成规范化；840 个候选专属文件有基线哈希。
- 135 题通过当前严格场景与重绘接口，可由用户点击原题 Pass：49 blocks、41 nets、21 views、12 special、12 cylinders。
- 135 张当前预览均完成两次 PNG / SVG 确定性重绘、布局/碰撞校验和实际逐图查看。24 张与历史 PNG 像素一致；其余记录渲染迁移差异，不冒称历史像素一致。
- 2198、2878 仅做已授权标签 offset 调整，原锚点、几何、题意、答案和原图不变，前后偏移和理由保存在来源说明。
- 正式库仍为 133 题（46 Analytics、71 PlaneGeometry、16 SolidGeometry），原有正式内容与批准指纹没有刷新，也未自动通过任何交付候选。

## 33 个 Pass 阻挡项

界面逐题显示原因，仍可查看原图、重绘和解答，或删除候选。

- 26 个多视图候选缺少对应三维模型证据，不能把投影图随意补成实体。
- 2024、2029、2181、2584 的混合图包含没有世界坐标/显隐绑定的物理 XY 对象。
- 2936 的面板尺度无法按当前统一投影契约无损合并。
- 2813、3031 的物理边界既标作可见又要求虚线，不能擅自改成隐藏边。

没有放宽现有渲染协议，或补造缺失几何证据来使 Pass 变绿。

## 已执行的测试范围

- 全 168 题实时服务端校验，与 135 可入库 / 33 阻挡声明逐项一致。
- 独立临时副本中，全部 135 题通过真实 importer 打包、测试专用审批和索引检查；135 个生成绘图类均可导入，普通 Solid Special 工作台的 no-op 图与候选 PNG 逐像素一致，几何对象可选。该副本的测试审批没有写回交付库。
- 后端测试覆盖 Pass / Delete 写入与清理、每个写入/删除边界回滚、进程强制退出后恢复、请求重放、跨线程/进程编号分配、过期内容、共享与未跟踪文件保护、未提交更改保护、路径/符号链接防御；正式编号与恢复后审核状态不一致时明确阻止入库，避免产生普通工作台无法读取的跳号。
- 真实 localhost HTTP 测试覆盖 Host / Origin / 会话令牌、重复头、坏 JSON、静态与图片路由，以及实际 Pass / Delete 和重放。
- 真实 app.js 的 17 项事件/状态检查通过，包含双击、图像失败、导航竞态、过期冲突、结果不明后的同请求重试、删除取消、放大弹窗、快捷键与空队列。
