# MathPalette 立体几何重绘协议

版本：1.2.0（2026-10-10）。适用于 `MathPalette/SolidGeometry/`。沿用平面几何的统一画布、冻结输入、代码重绘与核对报告，独立规定三维几何、投影、可见性和空间标注。机器样式以 [protocol.json](dataset_generator/protocol.json) 为准。

## 1. 每道图示的流程

1. 原样保存来源图片、题干及真实来源名称；只有图片时使用 `status="redraw_example"`，题干、答案为空，不推测求解目标，不占正式题号。
2. 列出空间点、棱、面、曲面、截面、轮廓线、隐藏线、辅助线、尺寸、标签和关系标记。区分明确条件、用于布局的构造，以及有待确认的解释。
3. 在三维世界坐标中构造几何，核对真实长度、半径、角度、平行、垂直、共面及归属关系。截图中的透视长度不能代替真实尺寸。
4. 选定与原图一致的投影；冻结投影矩阵、朝向、二维视窗、曲线采样和标签偏移。可见/隐藏区间单独冻结，不能由线条颜色或绘制先后隐式表达。
5. 生成不透明 768×768 PNG 与 SVG；核对空间关系、尺寸标签、投影、遮挡、轮廓和边界，再实际查看图片。
6. 重绘两次核对像素一致，保存来源、场景、协议、渲染器、入口脚本及输出哈希、依赖版本和核对明细。

正式题目须另行核对题干、答案和来源再登记。自动几何检查、Agent 图像检查和用户 Pass / Collect 是不同状态，不相互代替。

## 2. 文件布局与编号

```text
SolidGeometry/
  REDRAW_PROTOCOL.md
  README.md
  dataset_generator/
    protocol.json                              机器样式与容差
    common_renderer.py                         三维校验及二维投影绘制
    requirements.txt
    test_renderer.py                           投影、尺寸、遮挡区间等核对
```

正式题号使用 `Solid01`、`Solid02`……，与 `Ana`、`Plane` 独立；推荐 `solid_plotNN.py` 和 `class SolidNN`，在构造函数中显式记录 `self.id`、真实的 `self.source_dataset`、`self.query`、`self.answer`、`self.answer_type`、`self.subject="SolidGeometry"`、`self.level`。样例使用 `SolidExampleNN`。

新增题目时，将来源图保存在 `originals/`、PNG / SVG 保存在 `image/`、冻结场景保存在 `dataset_generator/scenes/`、核对报告保存在 `dataset_generator/reports/`，各文件按题号命名。当前正式题、场景和程序均按题号保存。

数据路径相对分支根目录；场景中的 `source_image` 相对场景文件。源码导入不写文件。`source_dataset="UserProvidedImage"` 只表示当前获取方式，须同时注明原始数据集未知，不能冒称 MathVerse、DynaMath 或 Custom。

## 3. 三维语义与构造

| 对象或关系 | 重绘要求 |
| --- | --- |
| 点、棱与面 | 每个对象有稳定 ID；点为有限三维坐标，棱绑定端点，面记录边界顺序。内部构造点不自动加名称或圆点。 |
| 平面与空间相交 | 区分空间相交、异面线和仅在投影中交叉；不能因二维交叉增加交点、短接或点标记。 |
| 平行、垂直、共面 | 在三维中核对，不能从投影角度推断。真实直角投影后不一定是直角，空间圆投影后可以是椭圆。 |
| 柱、锥、台与球 | 保存轴、半径、底面、顶点、截断范围及连接关系；统一投影整个模型，不能各自手画前后底面椭圆。 |
| 曲面轮廓 | 轮廓依赖观察方向；圆柱侧轮廓是投影的切线，不能直接连接两个投影底面的最低点。曲面轮廓不是额外的真实棱。 |
| 截面、开口与空腔 | 保存截平面及其与实体的交线、被移除部分、内外表面。实心半圆柱、开口槽、半圆管不可互换；厚度不能猜测补画。 |
| 辅助线与截面线 | 标明用途及是否为明确条件；不添加解题辅助线、求解结果或原图没有的坐标轴。 |
| 数值与单位 | 原有数字、小数精度、单位、角度符号完整保留。半径、直径、斜高、垂直高、棱长、轴长不得混淆。 |
| 空间角与二面角 | 记录实际对应的线/面及角的定义；二面角需记录用于表示平面角的两条射线，不能用屏幕两条边的夹角替代。 |

优先满足明确数学条件，再调整投影与整体构图。三维单位统一，真实几何只能整体作刚体变换或有记录的统一单位缩放；投影后只允许统一缩放和平移，不允许单独拉伸 x/y。真实长度、投影长度、标注线的页面长度分别保存。

几何距离绝对容差 `1e-8` 世界单位、相对容差 `1e-8`，角度绝对容差 `1e-7°`；这些是程序构造精度，不是来源截图的测量精度。信息不全、条件冲突或构图解释不唯一时登记 `ambiguities`，不能把推测标为已知条件。

## 4. 投影与可见性

### 4.1 投影

默认使用平行投影，按原图选择正交或斜投影。保存 `projection.kind`、`matrix`（2×3）、`origin`（3D）、`offset`（2D）及 `toward_viewer`（朝观察者方向）。

```text
screen_xy = matrix @ (world_xyz - origin) + offset
```

正交投影的矩阵两行必须是互相垂直的单位向量；斜投影允许深度方向的缩短与斜移，但必须有明确名称、参数和选择理由，不能冒充保距正交投影。`toward_viewer` 在矩阵的核中并确定前后朝向。场景修改投影时必须重新核对隐藏区间与轮廓。

保留原图前后、左右、上下关系。只有原图确有透视需求时才设计透视场景，需额外冻结相机内外参、裁剪面和齐次除法规则；**v1 重绘器不支持透视，输入会报错**，不能用默认 3D 相机悄悄替代。

### 4.2 可见线、隐藏线与轮廓

- 可见棱、外轮廓用黑色实线；原图明确展示的遮挡边用黑色虚线 `[4,3] pt`。源图未显示的隐藏边不自动补齐，另在记录中说明省略策略。
- 辅助线的虚线与隐藏边即使外观相同也须分别记录 `role` 和 `visibility`；截面及曲面轮廓也有各自的 `role`。
- 同一圆弧、曲线或棱部分可见时按参数区间切分，保存精确交界参数。虚线不得跨出该物体的真实轮廓。
- 相邻可见/隐藏区间无缺口、无重叠；虚线先画、可见线后画，交界共用端点。不能用文字白底遮挡几何线，也不能把整个后端半圆统一设为虚线。
- 面填充只表达明确区域、截面或材料差异；普通光照、渐变、纹理和装饰阴影移除。填充不负责推断遮挡；边线可见性必须显式记录。v1 多边形填充按冻结顺序绘制，不提供通用面深度排序。

当前采用 `visibility_mode="frozen_intervals"`：制作者根据原图与模型计算/核对并冻结可见性；通用重绘器检查区间和投影绑定，**不宣称实现任意实体的自动消隐**。解析轮廓可通过切线约束检查。复杂相互遮挡需增加专用几何校验，不能仅凭画图顺序判定正确。

## 5. 统一画布、线条与标注

| 项目 | 规则 |
| --- | --- |
| 输出 | PNG 768×768、不透明白底 `#FFFFFF`；同时导出 SVG；题干、答案和标题不画入正式图。 |
| 画布 | 7.68×7.68 inch、100 dpi；绘图区 `[0.05,0.05,0.90,0.90]`；禁止 `bbox_inches="tight"`。 |
| 二维视窗 | 冻结方形视窗，`aspect="equal"`；完整图示居中，至少留 5% 外边距，最长边目标占画布 86%。纵横长图保持比例，短边允许自然留白。 |
| 坐标系统 | 默认隐藏坐标轴、网格、刻度和边框；坐标题须声明专用规则。 |
| 线条 | 黑色、1 pt、固定抗锯齿；可见实线、隐藏虚线；不以更粗轮廓暗示额外条件。 |
| 字体 | DejaVu Sans、黑色；点名 18 pt，数值、单位、角标及其他文字 16 pt；点名斜体，数值与单位正体，未标顶点不额外画点。 |
| 尺寸线 | 与平面几何一致，采用平行虚线和两端实线连接；绑定被测三维端点，投影后保存垂直于被测方向的页面偏移。不使用箭头、独立端帽或括号。 |
| 标签 | 用 pt 保存偏移，默认水平；同时保存对齐方向；不添加遮罩。尺寸数值由已核对的世界长度及冻结小数位生成，单位与场景一致。 |
| 关系标记 | 仅保留原有直角、等长、平行、角弧等标记；空间直角标记在对应三维平面内构造后投影，不强行画成屏幕直角。 |
| 曲线 | 三维圆弧经同一投影采样；每个区间样本数冻结，投影折线弦误差 ≤ 0.1 px，不能随运行随机调整。 |

尺寸线偏移不修改数学端点；标签拥挤时只调整标签与统一构图。尺寸标注锚点可以是内部构造点，但不能因其存在在成图中添加点名、半径线或轴线。

### 距离范围标识（2026-10-10 补充）

需要明确整段或子段范围时，统一采用平面几何 Plane02 的样式：在被测线段的投影旁画与其平行的黑色虚线，两端用黑色实线连接到被测端点的投影，数值或字母放在虚线中部旁侧。虚线为 `[4,3] pt`，连接线为 1 pt 实线；不使用箭头、独立端帽或括号。文字与线留出间隔，不截断几何边，不用白底遮罩。原图旧式尺寸箭头、端帽和括号改为这一样式，其数值、单位、测量范围保持原样。

适用情形与平面几何一致：相邻子段、同一方向的总长和局部长度、跨越中间顶点的距离，以及文字靠近多条边而归属不清的距离。普通边长、半径或高度已经明确对应唯一线段时，可以继续使用旁侧文字，不强制添加尺寸线。

`dimensions` 保存被测三维端点 `points`、真实长度 `value`、单位、冻结小数位、页面偏移 `offset_pt` 和文字偏移 `label_offset_pt`。文字默认由真实长度生成；未知量（如 h mm）或来源没有单位的数值可以保存 `text`，不得把构造用的长度作为题目条件显示。测量语义在三维中核对；标识线在二维投影后的页面中构造，两端使用相同平移且连接线与投影方向垂直。这些线仅为距离标识，不属于实体棱、隐藏线或解题辅助线，不修改三维模型、投影与可见性。

重绘器自动核对真实长度、投影方向、垂直偏移和端点绑定，报告记录 `style="Plane02_parallel_dashed"`。标注改变后重新冻结方形视窗并检查文字间隔。相邻范围可共用连接位置，但不得叠加重复描边。


构图按几何轮廓、面填充、标签、标记及尺寸线的完整可见范围计算包围盒。包围盒中心与画布中心偏差不超过 2 px；最长边占比目标为 86%，允许 1 个百分点误差，全部内容至少保留 5% 外边距。仅改变二维方形视窗进行统一放大和平移，保持长宽比例；不得通过截图裁切、拉伸或改变输出尺寸实现放大。

制作时拟合并冻结 `view.xlim`、`view.ylim` 和 `view.layout`；正式重绘仍关闭 autoscale。字号改变后重新检查标签与边线的间隔，可调整页面标注和尺寸线偏移；三维坐标、投影矩阵、可见区间和尺寸绑定保持原样。

## 6. 冻结场景与重绘接口

使用 `scene_schema_version="1.0.0"`、`protocol_version="1.2.0"`。

| 字段 | 内容 |
| --- | --- |
| `id/status/subject` | 场景 ID、状态和 `SolidGeometry` |
| `source_dataset/source_image/source_note` | 获取来源、原图相对路径和真实题源是否已知 |
| `query/answer` | 样例为 `null`；正式题目有独立核对记录 |
| `world_unit/points` | 三维单位与完整坐标；不可见构造点仍可用于校验 |
| `projection/view` | 冻结投影、观察朝向与二维方形视窗 |
| `visibility` | 区间冻结模式、所绑定投影的 SHA-256、说明；投影变化时旧区间失效 |
| `objects` | 稳定 ID、`role`、可见性、圆弧局部基底与采样区间等 |
| `dimensions/labels` | 绑定对象或三维锚点的尺寸和文字，实际排版偏移另存 |
| `constraints` | 明确条件或构造检查及其 `basis`，不能把构造条件冒称题设 |
| `ambiguities` | 未提供信息、采用的解释及其限制 |

公共重绘器提供 `draw(scene_path, output_path=None)`、`validate_scene(scene)`、`image_bytes(scene, vector=False)`。当前实现 `segment`、`polyline`、`circular_arc`、`face`、`point`，以及 Plane02 式距离范围标识、点名/文字标签；曲面本身由其可见边界表达，不自动生成网格线。当前约束为 `distance`、`equal_length`、`parallel`、`perpendicular`、`collinear`、`coplanar`、`on_circle`、`angle`、`projected_tangent`。

直线/射线须先按冻结视窗裁剪成三维显示端点并保存无界语义。空间关系标记、复杂截面、球面、透视和自动消隐的通用构造尚未实现；新增对象或约束须先实现与校验再使用。未知类型、无穷坐标、失配版本、错误尺寸或退化投影明确报错，不静默忽略。

在 MathPalette 目录执行：

```powershell
python -B SolidGeometry/dataset_generator/test_renderer.py
```

`draw(scene_path)` 默认重绘输出到 `SolidGeometry/reproduced/`；传入 `output_path` 可指定 PNG 或 SVG 路径。每题制作入口应记录两次 PNG/SVG 重绘一致性、实际依赖和输入/输出指纹。固定依赖下要求像素一致，跨版本比较须区分渲染差异与几何变化。通用检查使用独立构造场景，不依赖外部题目或示例图。

后续 Base / Special 操作另定；不能直接套入 Analytics 的 Base1 / Base2，也不生成空插件、人工 Pass 或 Collect 记录。未来变体仍采用 `images/ + plugins/ + recipes.json + draw_variants.py + 全局索引`，操作必须声明是否改变三维几何、投影、可见性或仅改变页面装饰。

## 7. 验收与报告

- 来源副本哈希一致，真实题源未知时如实说明；样例不写成正式题目。
- 三维几何与二维布局分离，尺寸和单位保真；没有通过非等比缩放歪曲模型。
- 可见边、隐藏区间、投影交叉、截面归属和曲面切线逐一核对。
- 输出不透明 768×768，字体、线宽和留白统一；标签不遮边、不越界。
- 同输入两次输出像素一致；报告绑定场景、投影、源图、协议、脚本、渲染器和环境。
- 已实际查看 PNG 并单独记录检查范围；自动报告初始为待视觉检查，不自动声称用户审核通过。


## 正式数据收集（2026-10-10 更新）

本分支 `dataset.jsonl` 只包含正式通过题。用户审核记录统一在项目根目录 `provenance/approvals.json`，清理后的文件与版本指纹由 `dataset_tools/catalog.py check` 校验。未通过新题在独立暂存区制作，不放入正式清单。运行状态和临时重绘写 `.runtime/`。
