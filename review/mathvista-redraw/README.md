**全部待审核：216 道原题重绘 + 11 道明确改编。** 解析几何 6、平面几何 220、立体几何 1。正式题库 77 题与 master 均未改动。此目录仅供对照审核，不代表已通过。

## 第一次用 GitHub，按这个顺序看

1. 向下点击题号，直接在网页看原图、重绘图、题干、答案及改编记录，不用下载 ZIP。
2. 可以先看下面单列的 11 道改编题，再分批看其他题。每页都有上一题、下一题和返回目录。
3. 回到草稿 PR 的 Conversation（讨论）页，在底部留言。例如“MathVista 32：接受补充条件并通过”；或“MathVista 5：H 标签遮住线，请移动”。也可以直接在 dot 聊天告诉我。
4. Files changed（文件改动）适合逐行留言：点对应行左侧的 +，填写具体题号与意见，再提交评论。图片对照建议直接打开本目录中的题目页面。
5. 不需要点 Merge pull request（合并）。草稿 PR 只是集中讨论改动；逐题通过后再处理正式入库，合并本分支本身也不会把候选自动变成正式题。

## 审核时看什么

- 图中对象、点名、连线、角弧和尺寸标记是否正确；是否有遮挡或遗漏。
- 重绘是否保留原题数学关系，而非用官方答案倒推图形。
- 改编题重点检查改动前后文字、改动理由、新答案及推导；原官方答案单独保留。
- 自动检查和已有图像检查不能代替你的逐题确认。

## 复现与核验

已交付的冻结场景与 PNG 保持原哈希。此分支保留每题源记录、场景、脚本、公共绘图器、锁定依赖及检查报告；省略 ZIP、缓存、构造过程日志和重复 SVG。

在此目录安装 requirements.txt 后，运行 python reproduce_all.py。它逐题读取冻结场景重绘并比对 PNG 哈希。不要重新构造场景。跨依赖版本的像素变化需要重新检查。
