# MathPalette 平面几何重绘协议

版本：1.1.0（2026-10-10）。适用于 `MathPalette/PlaneGeometry/`。本协议沿用 Analytics 的统一样式、冻结输入和可复现核对方式，专门规定平面几何的关系、标记和图形保真。

## 1. 每道图示的流程

1. 保存来源图片与完整题干，明确真实来源名称。只有图片时可以制作图示样例，不能猜测题干、求解目标或标准答案。
2. 列出点、线段、直线、射线、圆、圆弧、区域及所有文字、角度和关系标记，区分“明确条件”和“展示布局”。
3. 明确条件优先于截图中的像素位置。用几何构造或约束求解得到满足条件的坐标，保留原图的连接关系、点顺序与整体布局。
4. 冻结坐标、视窗、标记位置和标签偏移，保存机器场景 `scene.json`。构造不在每次绘图时重新随机或拟合。
5. 生成 PNG 与 SVG，检查几何条件、尺寸、透明度、标注和越界情况，再实际查看图片，检查交叉、遮挡和标签归属。
6. 两次重绘核对像素一致，保存 `redraw_report.json` 中的来源、场景、协议、渲染器和输出哈希，以及实际依赖版本。

正式题目另需独立核对答案后登记。仅图示样例以 `status="redraw_example"` 保存，不冒充已审核题目或已 Pass 的 Special。

## 2. 文件布局与编号

```text
PlaneGeometry/
  REDRAW_PROTOCOL.md
  dataset_generator/
    protocol.json                       机器样式与数值容差
    common_renderer.py                  公共绘图器与约束核对
    requirements.txt
    test_renderer.py                    独立构造场景的通用核对
```

未来正式题目使用 `Plane01`、`Plane02`……连续编号，与 Ana 系列独立。推荐每题一个 `plane_plotNN.py` 和 `class PlaneNN`，在构造函数中显式记录 `self.id`、真实的 `self.source_dataset`、`self.query`、`self.answer`、`self.answer_type`、`self.subject="PlaneGeometry"`、`self.level`。没有题干和答案的样例不占正式题号。

数据路径使用相对于分支或样例目录的路径，不写个人机器绝对路径。导入模块不生成文件。

## 3. 几何语义与构造

| 对象或关系 | 重绘要求 |
| --- | --- |
| 点与连接 | 每个命名点有唯一 ID；逐一保留线段的两个端点和连接关系。标签的位置与锚点分开保存。 |
| 共线、顺序、延长 | 保留明确的共线关系与点的前后顺序。线段不自动延长成直线；射线只向规定方向延长。 |
| 相交 | 保留线段的相交情况及交点先后顺序。原图未命名的交叉点不自动加圆点、名称或条件；没有桥接标记的平面线段交叉按普通相交绘制。 |
| 平行、垂直、等长 | 仅根据题干或原图的明确标记登记约束，验证坐标满足条件；不能从“看起来差不多”推断并补画关系符号。 |
| 圆与切线 | 保留圆心、半径、点在圆上、切点和切线等明确条件；圆不能因非等比例缩放变成椭圆。 |
| 角度 | 保存角的三个点，第二个点是顶点；区分内角、外角和优角，保留数值与度符号，检查标注属于哪两条射线。所有带数字、字母（如 x°、θ）或编号（如角1、角2）的角均须配一条角弧，来源图没有弧线时也补画。 |
| 标记 | 一个几何角只对应一条角弧，禁止用双弧、多弧或重复对象表示同一个角。同一个角有多个标签或引出标注时共用一条弧；同一顶点的不同角分别配弧，嵌套角按半径区分。保留原有等长短划、平行箭头及组别。只有直角方框、没有数字或字母角标时保留方框，不补弧；标了90°或其他角标时仍配一条弧。 |
| 填充、颜色和线型 | 装饰性背景和色彩统一移除。表示区域、不同对象、辅助线或条件的填充/色彩/虚实线必须保留其可区分性并记录含义。 |

明确条件的数值校验容差：角度绝对误差 ≤ `1e-7°`；距离绝对误差 ≤ `1e-8` 展示单位，关系判断另用相对误差 ≤ `1e-8`。这是程序构造的核对容差，不代表截图可被量角到该精度。

构造坐标只服务绘图，不显示为题目给定坐标。无明确长度条件时可选择尺度；全图仅可作统一平移、旋转和等比例缩放，不能沿 x / y 分别缩放。保留原图朝向；确需镜像必须记录，因为镜像会改变左右和有向角。

对于信息不全或矛盾的原图，记录 `ambiguities`，说明采用的解释。不能把求解结果、推测的等长/平行或额外辅助线画入原图。

角弧仅明确已有角标的归属，不增加相等、角平分或其他条件。圆周上的弧度数标注属于圆弧量，不是由两条射线构成的角；保存圆心和弧端点作为语义绑定，不为此补画圆心连线或额外中心角。已有无标签的单弧关系标记可以保留，但同一个角仍不能出现多条弧。

## 4. 统一画布与样式

机器参数以 [dataset_generator/protocol.json](dataset_generator/protocol.json) 为准。

| 项目 | 规则 |
| --- | --- |
| 输出 | PNG 768×768，不透明白底 `#FFFFFF`；同时可导出 SVG。题干、答案、标题不嵌入正式重绘图。 |
| 画布 | 7.68×7.68 inch，100 dpi；禁止 `bbox_inches="tight"` 改变 PNG 尺寸。 |
| 绘图区 | `[0.08,0.08,0.84,0.84]`，`aspect="equal"`。按对象和标记范围选择并冻结方形视窗；至少留 8% 外边距。 |
| 坐标系统 | 默认隐藏坐标轴、刻度、网格和边框。如果题目明确依赖坐标系，应另行声明适用的坐标绘图规则。 |
| 线段和圆 | 黑色 `#000000`，1 pt，无装饰填充，固定抗锯齿；线型保留语义。 |
| 点 | 默认不额外画顶点圆点；原图有点标记时才保留，面积 36 pt²，边宽 1 pt。 |
| 字体 | DejaVu Sans，12 pt；单字母点名斜体，角度数字和度符号正体；文字纯黑。 |
| 关系标记 | 1 pt；尺寸以 pt 冻结。直角方框与等长/平行标记随对象方向旋转，不能随全图尺度改变其视觉大小。 |
| 标签 | 点名相对顶点用 pt 偏移，角度按角平分线方向定位或保存明确位置；避免与边、点名和其他条件重叠。 |

文字不得用白色背景遮住几何边。拥挤时调整标签偏移或全图布局，不能移动单个顶点破坏条件。原图线条在交点连续通过；不能为美观截断成不相交。

角弧从该角的第一条射线延伸到第二条射线，圆心为角顶点；优角按明确的优角方向画弧。冻结弧半径，保持弧线与角标文字有间隔；嵌套角不能共用弧线或重叠成多重描边。

## 5. 冻结场景与重绘接口

场景采用 `scene_schema_version="1.0.0"` 与 `protocol_version="1.1.0"`，至少包含以下字段：

| 字段 | 内容 |
| --- | --- |
| `id`、`status` | 场景标识与制作状态 |
| `source_dataset`、`source_image` | 真实题源名称及来源图片的相对路径 |
| `view` | 冻结的 `xlim`、`ylim`，视窗保持方形 |
| `points` | 点 ID 与完整浮点坐标 |
| `objects` | 具有稳定 ID 的几何对象、端点引用与标记参数 |
| `labels` | 绑定点或角的标签、文字与位置偏移 |
| `constraints` | 明确数学条件及拓扑关系的核对参数 |
| `ambiguities` | 信息不全或解释不唯一的记录 |

标签明确绑定点或角，不用文字像素位置代替几何关系。参数、浮点坐标和偏移完整保存。

角标采用 `type="angle"`、`points=[射线点,顶点,射线点]` 和 `arc_id`；已知数值保存 `degrees`，未知量或角编号保存 `text`。每个 `arc_id` 引用一个 `type="angle_arc"` 对象，弧的三个点及 `reflex` 必须与标签表示同一个几何角。引出标注或需原样保留的近似角度可使用 `type="text"`，同时保存 `angle_points`、`reflex` 和 `arc_id`。同角的多个标签引用同一个弧对象，不能重复添加弧。

圆弧量标签使用 `role="arc_measure"`，保存 `center` 和 `arc_points`，与角标区分。直角方框不代替带角标的角弧。公共绘图器检查漏绑、错绑以及同角重复弧；判断同角依据顶点坐标与射线方向，不仅比较点名。

公共重绘器当前实现线段、圆、圆弧、点标记、多边形、点名/文字/角度、角弧、直角方框、等长短划和平行箭头。直线与射线须先按冻结视窗裁剪，保存实际显示端点；它们的无界语义另外在场景说明中记录。未知对象或约束会明确报错，不能静默忽略。

当前约束核对支持 `angle`、`distance`、`collinear`、`between`、`parallel`、`perpendicular`、`equal_length`、`on_circle`、`intersection`。内角/优角的角度标签也核对数值。相交约束保存两条线段及是否相交，用于固定拓扑。

公共绘图器提供 `draw(scene_path, output_path=None)`，读取冻结场景并生成 PNG；指定 `.svg` 输出路径时生成矢量版。导入公共绘图器不写文件。

在 MathPalette 目录核对通用重绘器：

```powershell
python -B PlaneGeometry/dataset_generator/test_renderer.py
```

重绘不重新采样。未来变体应采用 `images/ + plugins/ + recipes.json + draw_variants.py + 全局索引`，冻结实际操作参数和输入哈希；其操作集合需另定。现阶段不将无网格、无刻度的几何图套入 Analytics 的 Base1 / Base2，也不生成空 Special 包或人工通过记录。

## 6. 验收与报告

- 来源图片保持原样，真实来源明确，题干与答案不靠猜测补全。
- 点、连接、标记、数值及交点顺序保真；明确约束核对通过，未引入额外条件。
- 每个数字、字母或编号角标均绑定且仅绑定一条弧；同角多标识共用弧，弧的顶点、两条射线及内角/优角方向正确。
- 输出不透明 768×768、等比例、无网格/坐标轴，字体和线宽遵循统一配置。
- 已实际查看 PNG；所有标签可辨认且归属明确，没有越界、遮挡或丢失度符号。
- 相同场景两次重绘像素一致；报告保存输入、输出哈希、依赖版本和几何核对明细。
- 自动数值核对与人工验收分开表述，未把自动生成称作用户 Pass。
